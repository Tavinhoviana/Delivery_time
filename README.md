# Delivery Performance Analytics System

## Overview
This project analyzes delivery operations across multiple hubs to identify inefficiencies and performance bottlenecks using SQL and Python.

## Objective
To simulate a real-world logistics environment and extract actionable insights about delivery performance.

## Key Features
- SQL-based data modeling (hubs, orders, riders)
- Repository pattern for database access
- Python-based analysis layer
- Automated detection of performance anomalies
- Optional visualization dashboard

## Insights Generated
- Average delivery time per hub
- Identification of slowest hubs
- Detection of performance imbalance
- System-wide performance overview

## Tech Stack
- Python
- SQLite
- Pandas
- Matplotlib
